# Plugin catalogue

The plugins of this repository, generated from their READMEs and changelogs
(see `docs/hooks.py`); the latest release is the topmost version in a
plugin's `CHANGELOG.md`. Each links to its README, with its settings, parameters,
phases and data transfers. The groups and subgroups are described in
[`plugins/README.md`](https://github.com/elixir-cloud-aai/foca-plugins/blob/dev/plugins/README.md).
